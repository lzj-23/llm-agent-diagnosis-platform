## Enterprise RAG

本机已确认存在该项目，仅用于本地对照，不把绝对路径写入新仓库配置。

- FastAPI 接口；

## AI-Inference-Benchmark

本机已确认存在该项目，仅用于本地对照，不把绝对路径写入新仓库配置。

已确认正式结果包含：

- `case`：模型、设备、上下文长度、提示类型、并发等条件；
- `protocol`：预热、正式请求数、超时、最大 token 等协议；
- `summary`：成功率、TTFT、E2E、吞吐和 token 相关指标；
- `resources`：CPU、内存、GPU 利用率、显存、温度和功耗；
- `requests`：单请求耗时、状态码、重试和错误。

已实现 `tools/service.py:benchmark_adapter`，实际读取一条正式结果并保留 TTFT、E2E、吞吐、成功率、显存及测量条件。比较和告警必须携带测试条件，不能把不同模型、并发或上下文下的结果直接归因。适配读取没有重新产生硬件测量。

## 禁止直接复用的内容

- 两个项目的 `.env`、密钥、本机绝对路径；
- 模型文件、完整数据集、缓存和大体积结果；
- 未经确认的生产经验或性能结论；
- 为了丰富项目而复制的原有模块。

## 合成数据计划

最终 fixture 为延迟异常、OOM、上下文配置错误、正常四类，各 3 个轻微变体。工具失败通过自动测试注入；原项目结果只用于本地格式兼容检查，没有复制原始日志或私有数据到公开评测集。
