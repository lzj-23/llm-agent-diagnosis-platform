# 验收标准

最终逐阶段证据见 STAGE_GATES.md。以下为准备期检查项存档，不将尚未实施的扩展等同于本次交付。

## 准备阶段

- [x] 项目目录与既有项目完全隔离
- [x] PRD 明确输入、处理、输出和不做事项
- [x] 架构定义 Agent、工具、存储、评测和安全边界
- [x] 盘点既有项目可兼容的数据结构
- [x] 后端可安装、健康接口可访问、测试可运行
- [x] 密钥和私有数据默认不进入版本控制
- [x] Git 仓库本地初始化，未配置远程、未上传

## MVP

- [ ] 四组合成故障场景都有确定性期望结果
- [ ] 工具层单元测试覆盖关键分支
- [ ] 单 Agent 报告通过结构化校验
- [ ] 每个结论带证据或证据不足标记
- [ ] 超时、重试、工具失败有可验证的降级行为

## 多 Agent

- [ ] 共享状态可持久化和恢复
- [ ] 并行步骤不会重复写入或覆盖证据
- [ ] 审核 Agent 能发现无证据结论和证据冲突
- [ ] 有单 Agent/多 Agent 对比实验

## 最终交付

- [ ] API、前端、数据库和队列可一键启动
- [ ] CI 全部通过
- [ ] README 能让新用户复现演示
- [ ] 评测数据、脚本、条件和结果可追溯
- [ ] 仓库无密钥、隐私数据和机器专属路径
- [ ] 简历和面试描述只使用验证过的事实
